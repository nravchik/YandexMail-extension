Яндекс Почта — версия 8.22.3.8

Изменение этой версии
Служебная вкладка больше не создаётся. Почтовая логика работает в невидимом offscreen-документе Manifest V3, а доступ к cookies, вкладкам, уведомлениям и кнопке выполняется через service worker. После обновления старая служебная вкладка этого расширения закрывается автоматически.

Требуется современный Chromium-браузер с API offscreen и runtime.getContexts (Chrome/Chromium 116+). Firefox не поддерживается.

Установка
Для Яндекс Браузера: перетащите CRX3 на страницу browser://tune и подтвердите установку/обновление. При обновлении браузер может запросить подтверждение нового разрешения offscreen.
Для установки из исходников: распакуйте ZIP в постоянную папку и загрузите папку с manifest.json через режим разработчика на странице расширений.
Приватный ключ подписи не входит в пакет.

Сохранённые изменения
Панель и логика из исходного расширения 8.22.3. Счётчик обновляется при действиях с письмами и подтверждённой смене аккаунта. Суммарный счётчик по умолчанию выключен. Удалены контекстный поиск, сбор и отправка статистики, лишние разрешения. Упрощены настройки. Добавлен тёмный режим, уменьшена иконка меню, подпись под ней белая, жёлтая линия в тёмной теме имеет непрозрачность 30%.

Проверено
Реальный изолированный Chromium 151, без почтового аккаунта: запуск offscreen-документа с tabId=-1; отсутствие служебной вкладки; защита от дублирования фонового документа; передача тестового списка писем в панель; API cookies и кнопки через service worker; фильтрация событий; сохранение темы и настроек; продолжение работы при закрытой панели; повторное создание фонового документа; отсутствие исключений JavaScript. Также проверены синтаксис всех скриптов, локальные ресурсы HTML и тесты обновления счётчиков. Структура и криптографическая подпись CRX3 проверены отдельно.

Ограничения проверки
Авторизация, получение реальных писем, переключение реальных аккаунтов, звук и системные уведомления после смены архитектуры отдельно с аккаунтом не проверялись. Проверка выполнена в Chromium; работу именно в Яндекс Браузере необходимо подтвердить на установленной сборке. Используется исходный сетевой протокол Яндекса, его доступность зависит от сервиса.
