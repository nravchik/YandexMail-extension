# YandexMail-extension

Неофициальное расширение для Яндекс Почты. Показывает непрочитанные письма во всплывающей панели и их количество на значке браузера. Проверяет почту в фоне без открытой вкладки.

Текущая версия — **8.22.3.8**. Для фоновой работы нужен браузер на базе Chromium с поддержкой `chrome.offscreen` и `chrome.runtime.getContexts` (в Chrome эти API доступны вместе начиная с версии 116).

## Что умеет расширение

- Показывает отправителя, тему и начало письма. Из панели можно открыть письмо, ответить, отметить прочитанным, удалить или отправить в спам.
- Переключает аккаунты и обновляет счётчик при смене аккаунта и действиях с письмами. По умолчанию на значке отображается счётчик текущего аккаунта. Сумму по всем аккаунтам можно включить в настройках.
- Поддерживает уведомления о новых письмах и тёмную тему для панели и настроек.

## Установка из исходников

1. Скачайте ZIP через **Code → Download ZIP** и распакуйте его.
2. Откройте страницу управления расширениями, например `chrome://extensions` в Chrome, и включите режим разработчика.
3. Нажмите **Загрузить распакованное расширение** и выберите папку, в которой находится `manifest.json`.

## История изменений

| Версия | Изменения |
| --- | --- |
| **8.22.3.8** | Служебную вкладку заменили невидимым фоновым документом Manifest V3. Service worker передаёт ему события браузера и выполняет запросы к браузерным API. При обновлении старая служебная вкладка закрывается автоматически. |
| **8.22.3.7** | Уменьшили иконку конверта в меню аккаунтов, сделали подпись белой и снизили непрозрачность жёлтой полоски в тёмной теме до 30%. |
| **8.22.3.6** | Добавили тёмную тему для панели и настроек. Выбор темы сохраняется. |
| **8.22.3.5** | По умолчанию выключили суммарный счётчик. Удалили контекстный поиск, сбор и отправку статистики, связанные разрешения и лишние ссылки в настройках. |
| **8.22.3.4** | Счётчик обновляется при подтверждённой смене аккаунта и обновлении списка аккаунтов. После действий с письмами серверная сверка запускается без прежней задержки. |
| **8.22.3.3** | Открытие письма из панели сразу запускает отметку о прочтении и обновляет счётчик. Повторное открытие того же письма не уменьшает счётчик второй раз. |
| **8.22.3.2** | Исправили создание контекстного меню, формирование адреса для cookie `ys` и обработку сообщений без получателя. Контекстное меню позднее удалили в 8.22.3.5. |
| **8.22.3.1** | Перенесли исходную панель и почтовую логику версии 8.22.3 на Manifest V3. Для фоновой работы на этом этапе использовалась служебная вкладка. |

## Проверка версии 8.22.3.8

В изолированном Chromium 151 проверили запуск без служебной вкладки, передачу тестовых писем в панель, обновление значка, сохранение настроек и восстановление фонового документа. Авторизацию, получение писем, смену аккаунтов, звук и системные уведомления с реальным почтовым ящиком после перехода на новую архитектуру отдельно не проверяли.

Подробности о сборке и проверках приведены в [README.txt](README.txt).
